What it does

Point it at a web app you're authorized to test, and it runs the whole engagement like a methodical penetration tester would.

🔎

Recon & mapping

Enumerates subdomains, endpoints, parameters, and tech to chart the full attack surface.

🛡️

OWASP WSTG testing

Works category by category through the OWASP Web Security Testing Guide — auth, access control, injection, and more.

✅

Validated findings

Confirms real issues with the lightest safe proof instead of dumping false positives.

🔑

Authenticated & multi-tenant

Tests logged-in flows and cross-tenant isolation — where the highest-impact bugs live.

📄

Reports, two audiences

Writes a technical report for engineers and a plain-English summary for stakeholders — both as PDF.

⚙️

Open & readable

Just Markdown instructions and small scripts. No fine-tuning, no black box — read every line.

How it works

A disciplined five-phase workflow — each phase feeds the next.

Scope & authorization

Confirms you're allowed to test the target and records the rules of engagement first.

Recon & mapping

Builds the attack surface: hosts, endpoints, parameters, technologies, and roles.

Vulnerability testing

Works the OWASP WSTG categories against everything it mapped.

Safe validation

Proves real impact with minimal, non-destructive proof-of-concept.

Reporting

Turns findings into clear, actionable reports for devs and leadership.

Install

Drop the skill where Claude Code discovers skills, then just ask for a pentest.

# Per project
git clone https://github.com/hassan-algo/open-sesame.git
cp -r open-sesame/.claude/skills/web-pentest .claude/skills/

# …then in Claude Code:
"Pentest my web app at https://staging.myapp.example — I own it. Start with recon."

⚠️ Authorized testing only. This skill is for systems you own or have explicit permission to test (your own apps, a signed client engagement, an in-scope bug-bounty target, or a CTF / practice lab). It's designed to refuse unauthorized targets and prefer non-destructive proofs. Using it against systems you don't have permission to test may be illegal — you are responsible for staying within scope and the law.
